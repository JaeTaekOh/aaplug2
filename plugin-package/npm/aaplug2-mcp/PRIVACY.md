# AA Plug 2: Privacy

Contact: https://aaplug.com

- **What is read:** project files of the app you connect, such as the manifest, build files, Info.plist, string files, README, icons and screenshots. They are read only on the computer running the AA Plug 2 server.
- **Network:** (1) when you connect a public GitHub repository, the server reads it through `api.github.com` and `raw.githubusercontent.com`; (2) shared review lessons with `https://aaplug.com/api/lessons` (see below). No analytics, ads, accounts or other telemetry.
- **Stored:** analysis results, your choices and generated files are saved in `~/.aaplug2` on that computer (or in `AAPLUG2_HOME`). Delete that folder to remove everything.
- **Review lessons:** when you report a store review result, AA Plug 2 learns from it on this computer only. A generalized lesson (store, guideline or ITMS code, short advice, counters) is saved in `~/.aaplug2/lessons.json`, with an anonymized copy in `lessons-export.json` for your own review. The lessons file never keeps the store's original message, app names, emails or keys; the original message stays only in that project's own folder. Delete those files to forget every lesson.
- **Shared review lessons (since 0.1.4):** to improve the checks for every user, each real (non-demo) learned review result sends one anonymized record to `https://aaplug.com/api/lessons`. It contains **only** `store` (`apple` or `play`), `codes` (guideline numbers such as `5.1.1(v)`, `ITMS-#####` codes, or a Google Play policy id from AA Plug 2's fixed table), `advice_id` (a key of that fixed table) and `event` (`rejected`, or `passed` after a later approval). Example: `{"v":1,"event":"rejected","store":"apple","codes":["4.8"],"advice_id":"4.8"}`. The tool result shows the exact record (`lesson.shared`).
  - **Never sent:** the store's message, app name, bundle or package id, project id, file paths, e-mail addresses, names, phone numbers, URLs, keys, review notes or any other free text. A Google Play policy name that could only be read from the message text is not shared at all.
  - **On the server:** one running count per store + codes + advice id (no rows per person or per app), plus the day it was last seen. IP addresses are used only as a salted hash for a one-hour rate limit and expire automatically; request bodies are not logged.
  - **Reading the feed:** AA Plug 2 downloads the combined counts (cached in `~/.aaplug2/shared-lessons.json` for 12 hours) and shows matching items as "From other reviews" reminders or warnings. Their titles and advice come only from AA Plug 2's own table; text from the server is ignored. They never become must-fix items.
  - Sharing is always on; there is no switch to turn it off. The built-in demo never sends anything. If `aaplug.com` cannot be reached (5-second timeout), everything keeps working on your computer.
- **Not collected:** no tokens, passwords or store credentials are requested, and nothing is ever submitted to Google Play or the App Store by AA Plug 2.
- **Your AI client:** the assistant you use (Grok Bot, Claude, Cursor, …) sees the tool results under its own privacy terms.
