한국어

AA Plug 2는 연결한 앱 프로젝트 파일을 사용자의 브라우저 안에서만 읽고 분석합니다. 파일, 분석 결과, 만들어진 자료를 MOTOR AA 서버로 보내거나 저장하지 않습니다.

GitHub 공개 저장소 주소를 넣으면 브라우저가 GitHub에서 공개 파일을 직접 받아옵니다. 토큰이나 비밀번호는 묻지 않습니다. 진행 상황은 다음에 이어서 할 수 있도록 이 기기의 브라우저 저장소(localStorage)에만 보관되며, “새 앱 연결하기”를 누르거나 브라우저 데이터를 지우면 삭제됩니다.

문의: motoraathailand@gmail.com

English

AA Plug 2 reads and analyzes the app project you connect only inside your browser. Files, analysis results and generated assets are never sent to or stored on MOTOR AA servers.

If you enter a public GitHub URL, your browser downloads the public files directly from GitHub. We never ask for tokens or passwords. Progress is kept only in this device’s browser storage (localStorage) so you can continue later, and is removed when you tap “Connect a new app” or clear browser data.
