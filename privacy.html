AA Plug 2 — Privacy Policy

Effective 2026-11-12

English · 한국어 · ภาษาไทย · 中文 · हिन्दी

English

AA Plug 2 reads and analyzes the app project you connect only inside your browser. Files, analysis results and generated assets are never sent to or stored on any server (the only exception is the anonymized review-lesson record described below).

If you enter a public GitHub URL, your browser downloads the public files directly from GitHub. We never ask for tokens or passwords. Progress and your language choice are kept only in this device’s browser storage (localStorage) so you can continue later, and are removed when you tap “Connect a new app” or clear browser data. Review results you paste are also turned into short, generalized lessons kept only in this browser (key aaplug2.lessons.v1) so later apps get the same checks; they never include the store’s original message.

Shared review lessons (since 0.1.4). To improve the checks for everyone, when you paste a real store result (not the built-in demo), AA Plug 2 sends one small anonymized record to https://aaplug.com/api/lessons: the store (App Store or Google Play), the guideline / ITMS / Play policy codes it found, a fixed advice id from AA Plug 2’s own table, and whether it was a rejection or a later approval. It never sends the store’s message, your app’s name, bundle or package id, project id, file paths, e-mail addresses, names or any other text. The server keeps only a running count per code and advice id (no rows per person). Your IP address is used only as a salted hash for a one-hour rate limit and is not kept. AA Plug 2 also downloads the combined counts and shows matching items as “From other reviews” reminders; their titles and advice come only from AA Plug 2’s fixed table. Sharing is part of how AA Plug 2 works and cannot be turned off; if the server cannot be reached, everything keeps working on your device.

Contact: aaplug.com

한국어

AA Plug 2는 연결한 앱 프로젝트 파일을 사용자의 브라우저 안에서만 읽고 분석합니다. 파일, 분석 결과, 만들어진 자료를 어떤 서버로도 보내거나 저장하지 않습니다(아래 익명 심사 교훈 기록만 예외).

GitHub 공개 저장소 주소를 넣으면 브라우저가 GitHub에서 공개 파일을 직접 받아옵니다. 토큰이나 비밀번호는 묻지 않습니다. 진행 상황과 고른 언어는 다음에 이어서 할 수 있도록 이 기기의 브라우저 저장소(localStorage)에만 보관되며, “새 앱 연결하기”를 누르거나 브라우저 데이터를 지우면 삭제됩니다. 붙여 넣은 심사 결과는 짧게 일반화한 교훈으로 이 브라우저에만 저장되어(키 aaplug2.lessons.v1) 다음 앱에도 같은 확인을 해 줍니다. 스토어 원문은 담지 않습니다.

공유 심사 교훈 (0.1.4부터). 모든 사용자의 검사를 개선하기 위해, 실제 스토어 결과를 붙여 넣으면(기본 데모 제외) AA Plug 2가 작은 익명 기록 하나를 https://aaplug.com/api/lessons로 보냅니다. 스토어(App Store 또는 Google Play), 찾은 가이드라인·ITMS·Play 정책 코드, AA Plug 2 자체 표의 고정 조언 ID, 반려인지 이후 승인인지만 보냅니다. 스토어 메시지, 앱 이름, 번들·패키지 ID, 프로젝트 ID, 파일 경로, 이메일 주소, 이름 등 다른 글은 절대 보내지 않습니다. 서버는 코드와 조언 ID별 누적 횟수만 보관하며(사람별 기록 없음), IP 주소는 1시간 요청 제한을 위한 해시로만 쓰고 보관하지 않습니다. AA Plug 2는 합산된 횟수를 받아 해당 항목을 “다른 사용자 심사에서” 알림으로 보여 주며, 제목과 조언은 AA Plug 2 고정 표에서만 가져옵니다. 공유는 AA Plug 2 동작의 일부라 끌 수 없습니다. 서버에 연결되지 않아도 기기에서는 모두 정상 동작합니다.

ภาษาไทย

AA Plug 2 อ่านและวิเคราะห์โปรเจกต์แอปที่คุณเชื่อมต่อ ภายในเบราว์เซอร์ของคุณเท่านั้น ไฟล์ ผลการวิเคราะห์ และไฟล์ที่สร้างขึ้นจะไม่ถูกส่งหรือเก็บไว้บนเซิร์ฟเวอร์ใด ๆ (ยกเว้นเฉพาะบันทึกบทเรียนรีวิวแบบไม่ระบุตัวตนที่อธิบายด้านล่าง)

หากใส่ลิงก์ GitHub สาธารณะ เบราว์เซอร์จะดาวน์โหลดไฟล์สาธารณะจาก GitHub โดยตรง เราไม่ขอโทเค็นหรือรหัสผ่าน ความคืบหน้าและภาษาที่เลือกเก็บไว้ในพื้นที่จัดเก็บของเบราว์เซอร์บนอุปกรณ์นี้ (localStorage) เท่านั้น และจะถูกลบเมื่อกด “เชื่อมต่อแอปใหม่” หรือล้างข้อมูลเบราว์เซอร์ ผลการรีวิวที่คุณวางจะถูกสรุปเป็นบทเรียนสั้น ๆ เก็บไว้ในเบราว์เซอร์นี้เท่านั้น (คีย์ aaplug2.lessons.v1) เพื่อใช้ตรวจแอปถัดไป ไม่มีข้อความต้นฉบับจากสโตร์

บทเรียนรีวิวที่แชร์ (ตั้งแต่ 0.1.4) เพื่อปรับปรุงการตรวจสำหรับทุกคน เมื่อคุณวางผลจากสโตร์จริง (ไม่ใช่เดโมในตัว) AA Plug 2 จะส่งข้อมูลแบบไม่ระบุตัวตนหนึ่งรายการไปที่ https://aaplug.com/api/lessons ได้แก่ สโตร์ (App Store หรือ Google Play) รหัสแนวทาง / ITMS / นโยบาย Play ที่พบ รหัสคำแนะนำคงที่จากตารางของ AA Plug 2 และว่าเป็นการปฏิเสธหรือการอนุมัติภายหลัง ไม่ส่งข้อความจากสโตร์ ชื่อแอป bundle / package id รหัสโปรเจกต์ เส้นทางไฟล์ อีเมล ชื่อ หรือข้อความอื่นใด เซิร์ฟเวอร์เก็บเพียงจำนวนนับต่อรหัสและรหัสคำแนะนำ (ไม่มีข้อมูลรายบุคคล) ที่อยู่ IP ใช้เป็นค่าแฮชสำหรับจำกัดคำขอ 1 ชั่วโมงเท่านั้นและไม่ถูกเก็บไว้ AA Plug 2 ยังดาวน์โหลดจำนวนนับรวมและแสดงรายการที่ตรงกันเป็นการเตือน “จากการรีวิวของผู้อื่น” โดยหัวข้อและคำแนะนำมาจากตารางคงที่ของ AA Plug 2 เท่านั้น การแชร์เป็นส่วนหนึ่งของการทำงานของ AA Plug 2 และปิดไม่ได้ หากเชื่อมต่อเซิร์ฟเวอร์ไม่ได้ ทุกอย่างยังทำงานบนอุปกรณ์ของคุณตามปกติ

中文

AA Plug 2 只在你的浏览器内读取和分析你连接的应用项目。文件、分析结果和生成的素材绝不会发送或存储到任何服务器（唯一的例外是下文所述的匿名审核经验记录）。

如果你输入公开的 GitHub 地址，浏览器会直接从 GitHub 下载公开文件。我们绝不会索取令牌或密码。进度和你选择的语言只保存在本设备的浏览器存储（localStorage）中，方便你下次继续；点击“连接新应用”或清除浏览器数据即会删除。 你粘贴的审核结果也会变成简短、通用的经验，只保存在此浏览器中（键 aaplug2.lessons.v1），供之后的应用使用；不包含商店原文。

共享审核经验（自 0.1.4 起）。为了改进所有人的检查，当你粘贴真实的商店结果（不是内置演示）时，AA Plug 2 会向 https://aaplug.com/api/lessons 发送一条匿名的小记录：商店（App Store 或 Google Play）、找到的准则 / ITMS / Play 政策代码、AA Plug 2 自有表格中的固定建议 ID，以及这是拒绝还是之后的通过。绝不发送商店消息、应用名称、bundle / package ID、项目 ID、文件路径、电子邮件地址、姓名或任何其他文字。服务器只保存每个代码和建议 ID 的累计次数（没有按人记录）。你的 IP 地址只以加盐哈希形式用于一小时的频率限制，不会保留。AA Plug 2 还会下载合计次数，并把匹配项显示为“来自其他人的审核”提醒；其标题和建议只来自 AA Plug 2 的固定表格。共享是 AA Plug 2 工作方式的一部分，无法关闭；如果无法连接服务器，一切仍会在你的设备上正常工作。

联系：aaplug.com

हिन्दी

AA Plug 2 आपके कनेक्ट किए गए ऐप प्रोजेक्ट को सिर्फ़ आपके ब्राउज़र के अंदर पढ़ता और जाँचता है। फ़ाइलें, विश्लेषण के नतीजे और बनाई गई सामग्री कभी भी किसी सर्वर पर न भेजी जाती हैं, न रखी जाती हैं (सिर्फ़ नीचे बताया गया गुमनाम समीक्षा-सबक रिकॉर्ड अपवाद है)।

अगर आप सार्वजनिक GitHub URL डालते हैं, तो आपका ब्राउज़र सार्वजनिक फ़ाइलें सीधे GitHub से डाउनलोड करता है। हम कभी टोकन या पासवर्ड नहीं माँगते। प्रगति और आपकी चुनी हुई भाषा सिर्फ़ इस डिवाइस के ब्राउज़र स्टोरेज (localStorage) में रखी जाती है ताकि आप बाद में जारी रख सकें, और “नया ऐप कनेक्ट करें” दबाने या ब्राउज़र डेटा साफ़ करने पर हट जाती है। आप जो समीक्षा नतीजे पेस्ट करते हैं, वे छोटे सामान्य सबक बनकर सिर्फ़ इसी ब्राउज़र में रहते हैं (कुंजी aaplug2.lessons.v1) ताकि अगले ऐप्स को वही जाँच मिले; इनमें स्टोर का मूल संदेश नहीं होता।

साझा समीक्षा सबक (0.1.4 से)। सबके लिए जाँच बेहतर करने के लिए, जब आप असली स्टोर नतीजा पेस्ट करते हैं (बिल्ट-इन डेमो नहीं), AA Plug 2 एक छोटा गुमनाम रिकॉर्ड https://aaplug.com/api/lessons को भेजता है: स्टोर (App Store या Google Play), मिले गाइडलाइन / ITMS / Play नीति कोड, AA Plug 2 की अपनी तालिका की एक तय सलाह ID, और यह कि यह अस्वीकृति थी या बाद की मंज़ूरी। स्टोर का संदेश, आपके ऐप का नाम, bundle या package ID, प्रोजेक्ट ID, फ़ाइल पाथ, ईमेल पते, नाम या कोई अन्य टेक्स्ट कभी नहीं भेजा जाता। सर्वर हर कोड और सलाह ID की सिर्फ़ कुल गिनती रखता है (व्यक्ति-वार कोई रिकॉर्ड नहीं)। आपका IP पता सिर्फ़ एक घंटे की दर-सीमा के लिए नमकीन हैश के रूप में इस्तेमाल होता है और रखा नहीं जाता। AA Plug 2 कुल गिनतियाँ भी डाउनलोड करता है और मेल खाने वाली चीज़ें “दूसरों की समीक्षाओं से” रिमाइंडर के रूप में दिखाता है; उनके शीर्षक और सलाह सिर्फ़ AA Plug 2 की तय तालिका से आते हैं। साझा करना AA Plug 2 के काम करने का हिस्सा है और बंद नहीं किया जा सकता; सर्वर तक न पहुँच पाने पर भी सब कुछ आपके डिवाइस पर चलता रहता है।
